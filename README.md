# Silence OS

A custom visual experience for ColorFit Pulse 2, with a Flutter companion app and an evidence-based firmware investigation.

- [Flutter app: run and build instructions](app/README.md)
- [Silence OS roadmap and architecture](docs/silence-os/README.md)
- [Firmware OS, screens and watchface research](docs/firmware/README.md)
- [Android APK, BLE and backend research](docs/README.md)

The initial app supports Android BLE discovery/GATT inspection and watchface design previews. Firmware installation, watchface compilation/transfer and health synchronization remain later milestones.
